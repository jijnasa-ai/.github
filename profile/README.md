# Jijnasa (जिज्ञासा)

**A small model that learns how to learn.**

Jijnasa is a research project by [Winsen Labs](https://winsenlabs.com).

*Jijñāsā* is Sanskrit for the desire to know.

---

Most AI models are trained once and then frozen. They know a great deal, and learn very little after that.

Jijnasa explores the opposite bet. Intelligence is the ability to learn something new, efficiently. We think that ability can live in a model small enough to run on your own computer.

### What we are building

- A small model and harness that teach themselves things they have never seen.
- It explores, predicts what will happen, runs experiments, and keeps what works.
- It gets faster at learning each new thing it meets.
- It runs on your own machine, private by default.

### How we prove it

We start with code, because code tells the truth: a program either works or it does not.

1. Learn a programming language that exists nowhere else, from its manual and by experiment.
2. Learn an unfamiliar library, and build working software with it.
3. Learn the next one faster.

We measure everything on material no model could have memorized. We report a result only once it has been measured.

### Status

Early research. Our repositories are private for now. We will share results, and a version you can try, when they are ready.
